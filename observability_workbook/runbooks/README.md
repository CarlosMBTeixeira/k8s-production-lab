# Runbooks

One per session, from [`_template.md`](_template.md), named
`NN-<session-slug>.md` to match the session file.

These are the deliverable. The cluster is destroyed and rebuilt every
session; these are what survives it, and what is worth having open on a
platform that is not this one.

| # | Runbook | Written |
|---|---|---|
| 01 | Loki as a datasource, and LogQL | ☐ |
| 02 | Dashboards and alerts reconciled by ArgoCD | ☐ |
| 03 | kube-prometheus-stack installed by ArgoCD | ☐ |
| 04 | Recording and alerting rules as a CRD | ☐ |
| 05 | ApplicationSets, sync waves, External Secrets | ☐ |
| 06 | OpenShift monitoring and logging | ☐ |

Write the row while the symptom is still fresh. A runbook reconstructed a
week later is a summary of the documentation, which is worth nothing —
the value is entirely in the fifth column, and that column is only
honest while you still remember what you believed before you were wrong.
